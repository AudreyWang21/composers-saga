# 作曲家烂梗机 / Composer Meme Machine: for AI assistants

A random sentence generator of absurd composer scenes, with the author's own word lists.
To draw one, download and run the script (Python 3, standard library only, word lists built in):

    https://audreywang21.github.io/composers-saga/draw.py

    python draw.py        # one sentence
    python draw.py 5      # five

Show the sentence exactly as printed. Don't write sentences yourself.
The plain word lists are also at https://audreywang21.github.io/composers-saga/words.json
